## 八、实施步骤

### 第 1 步 · 服务端骨架

```
cloudfunctions/api/modules/<key>/
├─ index.js     契约 + actions
├─ store.js     只碰自己的集合
└─ rules.js     纯逻辑
```

### 第 2 步 · 契约

```js
module.exports = {
  key: '<key>',
  name: '<中文名>',
  emoji: '<emoji>',
  version: 1,
  collections: ['m_<key>_<entity>'],
  defaults: { /* 可配规则 */ },
  actions: { summary, detail, act },
  on: {},
  onDecision: {}
}
```

### 第 3 步 · 注册

```js
// core/registry.js
const <key> = require('../modules/<key>/index.js')
const MODULES = [checkin, <key>]
```

### 第 4 步 · 建集合

云开发控制台建 `m_<key>_<entity>`，权限「所有用户不可读写」。

### 第 5 步 · 前端接口层

```js
// miniprogram/modules/<key>/api.js
var api = require('../../core/api.js')
module.exports = {
  summary: function () { return api.call('<key>.summary') },
  detail: function () { return api.call('<key>.detail') },
  act: function (data) { return api.call('<key>.act', data) }
}
```

### 第 6 步 · 页面 + 双注册

- `pages/m/<key>/` 四件套；
- `app.json` 的 `pages` 加一行；
- `core/modules.js` 加一条，`enabled: true`。

### 第 7 步 · 测试

至少覆盖：
- [ ] summary 返回首页要的字段；
- [ ] act 正常路径；
- [ ] act 重复执行（幂等/去重）；
- [ ] 余额不足/权限不足/未配对；
- [ ] 未授权集合访问被拦。

### 第 8 步 · 验收

- [ ] 新增目录 + 注册表 2 行 + `app.json` 1 行；
- [ ] 已有模块 0 修改；
- [ ] 两套测试全绿；
- [ ] 真机走一遍完整流程。
