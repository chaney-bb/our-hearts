# 吃饭点餐 · 规则文档

> 模块：`meal` ｜ 状态：🧊 占坑（**规则为提案，尚未实现**）
> 开发细节见 [`开发文档.md`](开发文档.md)。

---

## 一、总则

1. 每天一轮「今天吃什么」；一轮只产生一个结果。
2. 两个人各投一票；结果落库，双方看到同一个。
3. 不用爱心、不奖惩、不接外卖/支付。
4. 菜品池两人共享；谁都能加，删只能删自己加的（或软删除）。
5. 历史保留，供「最近吃过」参考。

---

## 二、每日一轮

| 项 | 规则 |
|---|---|
| 轮次 key | `coupleId + dateKey`（一天一轮） |
| 开始 | 当天第一次打开 `detail` 时惰性创建 |
| 结束 | 两人都投票 → `decided`；或当天结束仍未投 → 下一轮 |
| 跨天 | 新 `dateKey` → 新 round；旧 round 保留在历史 |
| 候选菜 | 创建 round 时对 `active` 菜做快照，之后加/删菜不影响本轮 |
| 未投票 | 保持 `voting`，不自动替投 |

---

## 三、投票规则

| 项 | 规则 |
|---|---|
| 每人每轮 | 1 票 |
| 改票 | 允许（`allowChangeVote: true`），以最新一票为准 |
| 已 decided 后 | 不能改；要改走 `reroll`（双方同意，可选） |
| 投不在候选里的菜 | `BAD_DISH` |
| 投已删除的菜 | 如果在本轮候选快照里，仍可投；否则拒绝 |
| 自己没加过菜 | 也能投（共享池） |

---

## 四、撮合规则

```
两人都投完：
  same  → result = 该菜
  diff  → 随机从两人的选择里二选一
  只有一人投 → voting
```

**为什么只从两人的选择里随机**，而不是从整个菜品池：
- 尊重双方「现在想吃」的意愿；
- 避免随机到没人想吃的菜；
- 结果可解释：「你俩一个面一个饭，随机选了面」。

**随机种子**：用 `round._id` 或 `createdAt`，保证同一次结果稳定；结果落库后不需要再随机。

**可选加权**：如果以后加 `weight`，可以在「两人选择」内部按权重随机；MVP 不做。

---

## 五、菜品池规则

| 字段 | 规则 |
|---|---|
| `name` | 2~20 字，去首尾空格 |
| `emoji` | 1 个 emoji（可选） |
| `tags` | 最多 3 个，每个 ≤6 字（辣/清淡/快手/汤…） |
| `weight` | 1~5 整数，默认 1 |
| 上限 | 50 道（active） |
| 删除 | 软删除 `active=false`；不影响历史 |
| 重名 | 同一 couple 内不建议重名；重名给提示但不强制 |

---

## 六、历史规则

| 项 | 规则 |
|---|---|
| 保留 | 最近 90 天（可配） |
| 展示 | 日期 + 结果菜 + 两人各选了什么 |
| 避免重复 | `avoidRecentDays=3` 时，最近 3 天结果菜不进入候选（可选） |
| 删除 | 不删历史；菜品删了也保留快照名字 |

> 历史里存 `resultName` 快照，避免菜品被删后显示空。

---

## 七、校验与错误

| 场景 | 错误码 |
|---|---|
| 菜品名太短/太长 | `BAD_NAME` |
| 菜品超过上限 | `TOO_MANY` |
| 不是自己的菜却要删 | `FORBIDDEN` |
| 投不存在的菜 | `BAD_DISH` |
| 本轮已 decided 还投 | `ALREADY_DECIDED` |
| 一天创建多轮 | 复用已有 round，不报错 |
| 未配对 | 门禁 `NOT_PAIRED` |

---

## 八、边界案例

| 场景 | 结果 |
|---|---|
| 两人都选同一道 | 直接 decided |
| 两人选不同 | 随机二选一，结果一致 |
| 一人投完就退出 | 保持 voting，等对方 |
| 当天没人投 | 次日新 round；旧 round 保持 voting（历史里标未完成） |
| 两人都投完后加新菜 | 不影响本轮结果 |
| 删除本轮候选里的菜 | 本轮仍可投/出结果（快照） |
| 同一天点「重来」 | 需要双方同意；否则会无限重来 |
| 跨时区 | 固定北京时间 `dateKey` |

---

## 九、明确不做

- 接外卖平台、下单、支付；
- 餐厅推荐/评分/地图；
- 营养/卡路里分析；
- 多人投票/群点餐；
- 用爱心奖惩吃饭。
