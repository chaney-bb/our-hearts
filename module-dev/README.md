# module-dev · 模块开发工作区

这个目录是**干活的地方**，不是「设计存档」。三件事：

1. **项目待办**：现在该做什么、做到哪了、验收标准是什么。
2. **项目交接**：给下一个 AI / 新同学 / 新聊天窗口的「快速上手包」。
3. **每个模块一个文件夹**：开发文档 + 规则文档。加新模块照 `_template/` 抄。

---

## 三、约定

| 约定 | 说明 |
|---|---|
| 一个模块一个文件夹 | 模块 key 和文件夹名一致（`checkin`、`shop`） |
| 每个模块两份文档 | `开发文档.md`（怎么改）+ `规则文档.md`（规则是什么） |
| 状态标记 | ✅ 已实现 ｜ 🟡 部分实现 ｜ ⬜ 未开始 ｜ 🧊 占坑 |
| 任务编号 | 沿用 `T1`–`T76`；新任务往后加，不复用旧编号 |
| 改完就更新 | 改了代码/规则，顺手更新对应文档的「状态 / 变更记录」 |
| 不写「大概」 | 规则数值、接口名、文件路径必须可核对 |
| 不放图 | 图放 `src/images/`，这里只引用 |

## 四、给 AI 的一句话

> 先读 `项目交接.md`，再读 `项目待办.md`；动手前跑两套测试；只改一个模块；改完更新交接文档的「当前状态」。
> 不要跨模块 `require`，不要绕过 `ctx.award`，不要手改生成物。
